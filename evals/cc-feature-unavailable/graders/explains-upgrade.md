PASS if the final message tells the user that the site's website version cannot render three.js yet and that the owner can upgrade the website version in the Marcapony dashboard to get it, and it does not claim a 3D scene was added. Offering a simpler alternative (for example a CSS animation) as an option the user can choose is fine, as long as it was not built.
FAIL if it says the scene was added, or it built an imitation of 3D with a hand-written canvas, WebGL or CSS 3D instead of explaining the upgrade.
